# 借空間：設計筆記

## 目標與邊界

目標是手機優先、不同年齡都容易開始的原創玩法探索。這是待驗證目標，尚未證明全年齡適用，也未完成全面近似作品檢索。不可宣稱全球首創、已證明留存或可獲利。

原型選擇一個熟悉手勢，配上一個需要逐步理解的結果：按住房間時，它會向左右與上下的鄰居借空間。核心問題是「怎麼分配有限空間，才能讓所有住戶都舒服」。

## 實際規則

房子總面積固定為 1。每層有兩間房；每層有高度比例 `h[r]` 和左右分隔比例 `w[r]`。

- 左房面積 `h[r] * w[r]`；右房面積 `h[r] * (1 - w[r])`。
- 按住左房增加 `w[r]`，按住右房減少它。
- 該樓層同時長高，從直接相鄰樓層、依其高於最低高度的可用空間比例取出高度。
- 單層時只調整左右寬度；不增加總面積。
- 每個房間需要的面積由關卡的已知有效配置計算，再乘上 0.91，保留容錯餘裕。另有 0.002 的判定容差。
- 住戶數目是視覺敘事；不是以人數直接推導需求的公式。需求條與表情才代表當前舒適狀態。後續試玩需確認這是否造成困惑。
- 寬度比例限制在 0.20–0.80；多層的高度下限為 0.16、可成長上限為 0.70。第三關的初始樓層配置有 0.72 的高度，分享後能自然回到上限內。
- 提示有限深度搜尋幾步可改善全屋需求缺口的調整；可能先建議已舒服的房間，不代表最短解，也不保證任意中途局面一步就能改善。

尺寸限制是可操作性的設計意圖，仍需真機確認觸控目標和手指遮擋。

以下文獻為先前討論已查閱的來源。文獻研究的遊戲與本原型不同，不能將結果視為本遊戲的實證。

## 尚未實作的商業化方向

使用者希望免費進入、以延續挑戰的資源消耗作為可能的付費方向，不採付費解鎖完整版。本版先驗證核心機制，沒有改變這個產品方向，也沒有導入真實付款或廣告。

未來可評估有限調整次數下的額外調整、特殊搬家工具、金幣取得與消耗。要先確認玩家喜歡並理解當前局面；不透過暗中修改需求或不可解局面製造付費理由。支付平台、兒童使用、價格、廣告、平台規範與真實收益皆未評估。

## 下一個設計決策

1. 表情、需求條是否足以讓人理解「為什麼還不舒服」。
2. 同時借寬度和高度是否難以預判；必要時先試只改一個方向的比較版。
3. 連續按壓與輕點是否讓人感到有策略，而不是試到成功。
4. 是否值得增加家具、連接條件等機制；先避免擴大規則負擔。
