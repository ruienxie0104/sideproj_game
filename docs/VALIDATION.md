# 驗證紀錄

日期：2026-10-21（Asia/Taipei），版本 0.4.0。

## 已完成

- `npm run check`：11 個 JavaScript 檔案的語法檢查，以及 **84 項 Node 自動測試**通過。
- 24 關均用實際 `advance()` 控制操作抵達完成狀態，並有目標調整次數內的操作路徑。固定路徑在 30/60/120Hz 模擬下通過。
- 面積守恆、相鄰借用、尺寸界限、寬度／高度／面積上下限、無效輸入、快照與長幀限制。
- v2 星星、目前關卡與教學移轉；v3 損毀時回讀 v2，原 key 不覆寫。
- 通關但尚未選擇的心意能保存；選擇限當關住戶；重玩／重新載入不重複累積。
- 四種動物均可在第 5 次有效好感後領養，滿好感不再消耗心意；領養只能一次。
- 逐關順序下，窮舉所有可達好感計數分支，24 關內均能集滿四種朋友。另檢查每種至少有 20 個出現關卡，其他三種最多消耗 15 個，故自由選關也保有 5 次機會。
- 家具需四個不同關卡解鎖；檢查領養門檻、移動不複製、占位替換、收回、配色與位置儲存，以及損毀資料清理。
- 用 Web Audio stub 檢查：首次操作前不啟動、音樂只有一個排程、音效獨立、音量零、切背景暫停、頁面快取恢復、延遲拍點不補播成一串音符、無音訊 API 時不阻擋遊玩。這些沒有實際播放聲音。
- 靜態 HTML 標籤配對、ID 唯一性，以及 JavaScript 的固定 ID 引用檢查通過。
- 本機 4173 伺服器的首頁內容與本次 `dist/index.html` 完全一致；`audio.js` HTTP 200 且 MIME 為 `text/javascript`。

## 第四版新增的已完成檢查

- 三星當局給一份飼料；同局復原後再過關不重領，重新開局可以再取得。判定使用當局星數，不使用歷史最高星數。
- v3 舊紀錄按已三星關卡數補發一次，花掉飼料再重新載入不會重發；寵物、選擇台帳與家具位置保留。
- 餵食需已領養且庫存足夠；只扣一份，只成長指定動物。2/5/9 次的互動與家具解鎖、保存、錯誤資料清理已測。
- 四隻動物模擬走動 15,000 幀，檢查全部有移動、留在房內、不進入九個家具腳下矩形範圍；成熟動物會午睡，未解鎖者不會。
- 按腳下 y 座標排序，走到家具後方／前方時有相應的數值層次。這不等於實際畫面遮擋已驗收。
- 用離線 DOM stub 檢查所有已領養動物同時建立、花冠條件、布置時全員隱藏、切背景與 reduced-motion 停止更新、頁面恢復。此測試不啟動瀏覽器，不驗證 CSS 渲染或真實觸控。

## 尚未完成

- 瀏覽器自動化的本機 URL 存取被政策拒絕；未透過替代瀏覽器繞過限制。第四版未取得實際畫面、觸控、完整對話框流程與輔助科技的 E2E 通過證據。
- 尚未實際聽取背景音樂，不能以模擬排程測試代替聽感或手機播放測試。
- 尚未完成 iOS Safari / Android Chrome、橫向、小尺寸螢幕、主畫面安裝實測。
- 實際瀏覽器的儲存拒絕情境、跨版本遷移與家具重新載入仍待手動驗收；純資料層已測。
- GitHub Actions 設定存在，但本紀錄不代表遠端 workflow 已成功執行。
- 第一版與第二版的使用者質性回饋，不代表第四版留存率、難度或收益已有驗證。

## 手動驗收清單

- [ ] 進入時是首頁，三個主要入口清楚，底部導覽不遮擋內容。
- [ ] 從遊戲進首頁／小家，按壓立即停止，不會突然跳出上一關的過關視窗；回到旅程保留尚未完成局面。
- [ ] 第一、四、五、九關的基本規則、寬沙發、高植物、小窩上下限正確。
- [ ] 復原、提示、重玩與星星紀錄正常；新十二關可以實際操作通關。
- [ ] 通關出現當關實際動物，第一次選擇加一好感；重玩不重複領取。
- [ ] 暫不選動物，首頁可補選；刷新後仍保留。
- [ ] 同一動物集滿五次可領養，小家顯示正確角色並可切換。
- [ ] 布置格子、替換、移動、收回與配色正常，刷新後保留。
- [ ] 布置模式不誤觸照顧寵物；完成布置後能摸摸、給點心、玩耍。
- [ ] 背景音樂與音效分開控制，音量正常，切到背景暫停。
- [ ] 連續切換導覽不重疊音樂，回到前景或頁面快取恢復也正常。
- [ ] 過關視窗與手帳可捲動、關閉，鍵盤焦點回到可見位置。
- [ ] 320px 螢幕沒有整頁橫向溢出；角色、願望與觸控區域可用。
- [ ] 舊 v2 星星保留，舊關可補領心意，完成街區家具解鎖。
