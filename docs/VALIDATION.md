# 驗證紀錄

日期：2026-10-21（Asia/Taipei）。

## 已完成

- `npm run check`：前端、規則與伺服器 JavaScript 語法通過。
- 第二版 Node 內建測試共 38 項通過（第一版為 14 項）。
- 12 關均由實際 `advance()` 控制操作找到可達舒適狀態的路徑，不只是驗證一張理論目標配置。
- 所有關卡都有目標調整次數內的可達路徑，並在 30/60/120Hz 模擬下通過。
- 驗證寬度、高度與面積上限會各自阻止錯誤過關；星星不重複累加、收藏必須完成四個不同小家。
- 驗證損毀／未知進度資料會被清理，第二版不覆蓋第一版 storage key。
- 檢查面積總和不變、只向相鄰樓層借高度、寬高界限、快照隔離、無效輸入與長幀限制。
- 本機 HTTP：首頁與 `engine.js` 回應 200，JavaScript MIME 正確，遺失資源回應 404。

## 尚未完成

- 瀏覽器自動化因存取政策拒絕本機 URL 而未執行，沒有以替代瀏覽器繞過限制。
- 第一版使用者已自行試玩，回饋是概念不錯但單調；這不是第二版的驗證結果。
- 第二版尚無實際手機觸控、瀏覽器渲染、鍵盤過關流程、音效和螢幕閱讀器的 E2E 通過證據。
- 尚未完成 iOS Safari / Android Chrome、橫向、小尺寸螢幕與主畫面安裝實測。
- 進度儲存拒絕與損毀資料有程式處理，但尚無實際瀏覽器情境驗證。
- 尚未進行不同年齡試玩、留存分析、收益測試或全面競品機制檢索。

## 手動驗收清單

- [ ] 第一關長按左房，兩房同時微笑後出現過關畫面。
- [ ] 下一關、返回關卡、重玩、復原均能使用。
- [ ] 按住後移出房間再放開，不會持續成長。
- [ ] 切換分頁、失焦或觸控中斷後，成長停止。
- [ ] 輕點微調、提示、鍵盤 Enter / Space 的次數紀錄合理。
- [ ] 重新整理後能回到目前關卡，保留個人最佳。
- [ ] 320px 寬度至平板畫面無水平溢出，最小房間的內容可讀。
- [ ] 音效預設關閉，開關不影響遊玩。
- [ ] 對話框可關閉，焦點能回到可操作位置。
