# 第一輪試玩

這是小規模探索，不是市場或全年齡代表性研究。先找不同遊戲經驗與年齡的少量試玩者，分別記錄裝置與操作方式，不急著追求遊玩時間最大化。

## 第一段：不先口頭教規則

1. 打開第一關，請對方自行試玩。
2. 觀察第一次操作是否成功，是否知道放手能停止。
3. 第一關後詢問：「你剛才做了什麼？另外一間房為什麼變小？」
4. 第三關後詢問：「哪幾間房會受到影響？你準備先調哪裡？」
5. 完成一關後先不催促，觀察是否自行開始下一關。

## 第二段：針對性追問

- 「哪次操作最有成就感？」
- 「哪次結果和預期不同？」
- 「你是覺得自己想通了，還是剛好按到？」
- 「如果再玩一次，你會改哪一步？」

## 判斷方式

優先看是否看懂、能預判、想試不同策略。不要把無法過關造成的長時間停留視為成功留存。先保留個別觀察，不把小樣本百分比當作普遍效果。

目前沒有收集任何試玩資料。遊戲也沒有遠端分析或自動蒐集個資。

## 第二版追加比較

先讓第一版試玩者直接試第 4、5、9 關，再玩一個混合需求關卡。

- 是否理解「面積足夠但還不夠寬／高」？
- 小貓「太空了」時，是否知道要去按鄰居來縮小它？
- 完成後是想看看新住戶，還是想重玩拿星？請記錄原話。
- 新家具與角色是否遮擋操作，尤其是最小房間？
- 星星目標是否讓人想改善策略，還是只是反覆小幅亂按？
- 日夜主題下的狀態文字是否都看得清楚？

第二版尚無試玩回饋；以上都是待驗證項目。
