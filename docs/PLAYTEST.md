# 第三版試玩計畫

第二版已有使用者自行試玩並回饋「還不錯」。第三版仍待實際裝置驗收與體驗回饋。以下是待執行清單，沒有宣稱已蒐集留存或不同年齡的代表性資料。

## 建議試玩路線

1. 重新整理首頁，觀察是否看得出「去解謎」「認識動物」「布置小家」三件事。
2. 在首頁開啟輕音樂，再試調音量、音效獨立開關；切換分頁後返回。
3. 完成前五關，每關可選狗狗布丁增加好感，確認第五次能主動領養。
4. 第四關完成暖陽小巷後，應取得盆栽。領養後進入小家，擺上坐墊與盆栽。
5. 試著搬動同一件家具、擺進已占格子、收回家具、換牆色；重新整理，確認結果保留。
6. 完成一關但先不選動物，從首頁補選；再重玩相同關卡，確認不重複加好感。
7. 到街區地圖試第 13、17、21 關，觀察新配色、難度與住戶組合。
8. 先不催促繼續，觀察玩家會選擇再玩一關、翻動物手帳，還是回家布置。

舊的 v2 玩家應直接保留星星；可先從首頁待領心意補選朋友，不必重刷前五關。勿清除原本網站資料來測遷移；用獨立測試瀏覽器設定檔保留原存檔。

## 手機與無障礙觀察

記錄裝置、作業系統、瀏覽器、螢幕尺寸與操作方式。

- 320px 寬至平板，不應有整頁水平捲動；家具架可局部橫捲。
- 長按不應選字、誤捲動或叫出選單。最小房間的狀態需可讀。
- 過關視窗較長時，能捲動到選動物與下一關按鈕。
- 開啟視窗、切換首頁／小家之後，Tab 焦點仍到可見且可操作位置。
- 減少動態效果系統偏好下，角色與轉場動畫應停用。
- 音量為 0 時應安靜，切到背景不繼續播放；iOS Safari、Android Chrome 分別測試。

## 判斷方式

延續前版重點：玩家能否預判空間流動，而不是單純試到成功。第三版再觀察是否出現自己想完成的領養或布置目標。若只是被獎勵流程拖慢，不把停留時間增加當成成功。小規模試玩結果保留個別差異，不推廣為全年齡或商業留存結論。


## 第四版：走動與養成

1. 先記錄舊版三星關卡數，再刷新，核對補發的飼料與原本家具。
2. 在小家同時看兩位以上動物 30 秒，依序把植物放中間、前後排；觀察走動、停留與前後遮擋。
3. 進入布置模式，確認動物退場且所有物件清楚。完成布置後，走動繼續。
4. 用同一位朋友餵食到 2、5、9 次，體驗接球、隨機午睡、花冠及三件成長家具；中途刷新核對紀錄。
5. 確認重玩三星有飼料、同局復原重過不重複發；舊紀錄三星但本局只有兩星不能領飼料。
6. 問：「現在餵食有什麼用？你下一個想達成的目標是什麼？」記錄是否真的注意到互動與家具變化。
7. 觀察 2/5/9 次門檻是否太快，以及重玩簡單關取得飼料是否很快變得單調。下一輪可比較輪流照顧不同寵物的委託目標；本版未加入每日任務或期限。
