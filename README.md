# 借空間 · 我們的小家

手機優先、單指操作的空間分配解謎遊戲原型。**按住房間借空間 → 讓鄰居住得舒服 → 選擇喜歡的動物 → 領養 → 用街區禮物布置小家。**

目前版本 `0.3.0`。新增長期陪伴與布置循環，趣味、留存與商業性仍待試玩驗證。

## 開始遊玩

需要 Node.js 20 或更新版本，無須安裝套件。

```bash
git clone https://github.com/ruienxie0104/sideproj_game.git
cd sideproj_game
npm run dev
```

開啟 [http://localhost:4173](http://localhost:4173)。首頁提供繼續旅程、動物手帳與我們的小家。原創背景音樂由首頁的音樂按鈕或右上角 `♪` 開啟。

前端原始碼就在 `dist/`，可由一般靜態伺服器提供。需透過 HTTP/HTTPS；直接雙擊 HTML 的 `file://` 模式不支援 JavaScript modules。本次僅保留本機與 GitHub，沒有額外 Sites 發布。

### 手機試玩

電腦與手機連同一個可信任的 Wi-Fi，執行：

```bash
HOST=0.0.0.0 npm run dev
```

手機瀏覽器開啟 `http://電腦的區域網路IP:4173`。手機上的 `localhost` 代表手機自己。預設 `npm run dev` 僅綁定電腦本機；可用 `PORT=4174 npm run dev` 更換連接埠。已有 manifest，尚無 service worker，未承諾離線可用。

## 第三版新增

- **首頁與導覽**：插畫小屋、繼續旅程、通關進度、待選心意入口、動物手帳與小家。
- **24 關、6 個街區**：保留前 12 關，新增海風花園、奶油小鎮與雲上小屋。每個街區四關，各自有配色及家具獎勵。
- **四位朋友**：兔兔棉棉、小狗布丁、小貓芝麻、小熊栗栗；更新 SVG 角色的毛色層次、耳朵、眼睛、配件與陰影。
- **通關心意與領養**：第一次通關後，在當關實際出現的動物中選一位，好感 +1。同一動物集滿 5 次即可領養。
- **可布置的小家**：一件初始坐墊及六件街區家具；3 × 3 擺放位置、移動、收回、三種牆面配色。已領養的動物共享這間小家，可切換陪伴對象。
- **輕量陪伴**：摸摸、點心、玩耍，各有文字與動作回饋。這版沒有飢餓、成長或經濟模擬，離開也不扣進度。
- **原創背景音樂**：Web Audio 合成的 16 小節音樂盒旋律與伴奏，不載入外部音檔。音樂、音效分別開關，提供共用音量控制；切到背景會暫停。

### 心意如何計算

每個不同關卡可選一次，重玩仍可改善星星紀錄，但不重複發放心意。選擇前離開或重新整理都不會丟失：從首頁「通關心意」補選即可。好感已滿的朋友會停用選取，保留心意給其他朋友；若當關全員已滿，該關無需再選。選定後不能改選。

四種動物各出現在至少 20 關。其他三種最多合計使用 15 次心意，因此每種都保留至少 5 個可選關卡；不會因選關順序而耗盡某種動物的領養機會。這是獎勵配置保證，並非玩家體驗的實測結果。

### 家具如何擺放

先領養至少一位寵物，進入「我的小家」。選擇家具後點地板一格，即可擺放；同一件家具只有一份，再點其他格就是移動。放進已佔用的格子會把原家具收回架上。「收回家具」模式可點格子移除。完成布置後，再摸摸或陪寵物玩。

## 解謎玩法

- 按住房間：向同層另一間房借寬度、向直接相鄰樓層借高度。放開停止；輕點微調。
- 空間有限，讓一間變大，其他房間就會變小。
- 願望有四種：面積足夠、沙發需要寬度、植物需要高度、小窩面積不能過大或過小。看房間的圖示與狀態文字判斷需求。
- 第 4、5、9 關首次介紹寬度、高度與小窩規則；之後混合運用。
- 每關三顆星：完成小家、目標次數內完成、沒有使用提示。沒有倒數，沒滿星仍可繼續。
- 可復原最近 100 次調整；復原還原次數，但不清除本局已用提示的紀錄。重來會開始新的一局。
- 街區地圖可選全部關卡。鍵盤用 Tab 選房間，按住 Space 或 Enter；家具與導覽也可用鍵盤操作。

## 存檔與聲音

- 第三版儲存於 `borrow-space-v3`。首次讀取會從 `borrow-space-v2` 保留星星、已見教學與目前關卡；v2、v1 原始紀錄不覆寫。舊的通關關卡可以補選動物，已完成街區的家具直接保留。
- 存的是已完成關卡與收藏，不包含未完成的房間配置。同一次開啟期間，從首頁或小家回到旅程會保留未完成局面；重新載入頁面或完成當局後，繼續旅程會找最早未完成關卡。全部過關後可再訪。
- 所有進度、家具位置、配色、音量皆留在該瀏覽器與網址來源下。清除網站資料會清除存檔；不同主機名、連接埠或裝置的紀錄不互通。
- 音樂與音效預設關閉。瀏覽器需要一次使用者操作才能啟動聲音；已開啟的偏好會保留，下次進入後操作導覽即可恢復。
- 無帳號、遠端分析、外部字型、第三方執行期套件、付款或廣告。

## 開發與驗證

```bash

npm run check
```

目前 **74 項自動測試**，包括 24 關的可解性、30/60/120Hz 目標路徑、規則與守恆、v2 移轉、好感與領養、家具擺放與存檔、音樂排程及背景暫停。GitHub Actions 設定為執行相同檢查，遠端執行狀態需另行確認。
